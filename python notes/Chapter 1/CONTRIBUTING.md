# 🤝 Contributing to Learn-Python

Thank you for wanting to improve this course! This project only stays high-quality because of community review.

## How to Contribute

1. **Fork** the repository.
2. **Create a branch**: `git checkout -b fix/chapter-05-typo`
3. **Make your change** — follow the existing chapter structure (`README.md`, `notes.md`, `exercises.md`, `solutions.md`, `quiz.md`, `project.md`).
4. **Test any code samples** — every snippet must actually run on Python 3.10+.
5. **Submit a Pull Request** with a clear description of what changed and why.

## What We're Looking For

- ✅ Fixing factual errors or outdated syntax
- ✅ Clarifying confusing explanations
- ✅ Adding missing edge cases to examples
- ✅ New practice questions (with solutions!)
- ✅ Translations of chapters into other languages
- ✅ Diagram improvements (Mermaid)

## What We're NOT Looking For

- ❌ Removing beginner-friendly explanations to make things "more concise"
- ❌ Code style rewrites with no functional improvement
- ❌ Unexplained solutions (every solution must teach *why*, not just show code)

## Style Guide

- Use clear, simple English — avoid unnecessary jargon.
- Every new concept needs: definition → why it exists → syntax → example → common mistakes.
- Use emojis only in headings, sparingly.
- Include expected **output** for every code block.
- Keep line length reasonable for readability in GitHub's renderer.

## Code of Conduct

Be respectful, be patient with beginners asking questions in issues, and remember everyone starts at zero.
